## M1 — done (2026-08-22)

- **Portfolio**: 12 real DOHMH establishments selected by camis from
  `db.establishments`. 8 salad restaurants (modeled to source from
  DOLE FRESH VEGETABLES INC / FRESH EXPRESS INCORPORATED / TAYLOR FARMS, INC.)
  + 4 other-cuisine restaurants (modeled to source from their nearest hub).
  Each carries `provenance.class='modeled-portfolio'` + `distributor_link.class='modeled-link'`.
- **Modeled supplier links**: the `distributor` field on each operator_site is
  the recalling_firm (e.g. "DOLE FRESH VEGETABLES INC") for produce sites, or
  the nearest hub name (e.g. "RESTAURANT DEPOT") for non-produce sites. The
  exposure join is `operator_sites.distributor == recall.recalling_firm`.
  NOTE: the distributor-scorecard.json uses short names ("DOLE") but the
  recalls collection uses full names ("DOLE FRESH VEGETABLES INC"). The
  `distributor` field on operator_sites uses the FULL name to match recalls;
  the $lookup to distributors (short names) returns [] — M2 needs the
  distributor's class1 count; get it from `db.distributors` by matching on
  the short name, or from the scorecard aggregation.
- **exposure()**: delegates to `db.queries.exposure()` (the $match+$lookup
  aggregation) and sorts by camis for determinism. DOLE Class I recall
  F-0757-2022 exposes 5 salad sites.
- **matches()**: severity gate (Class I > II > III) + relevance gate
  (supplier | allergen | category — must match at least one if specified).
  DEFAULT_PROFILE: min_severity=Class I, allergens=[peanut,...,shellfish],
  categories=[salad,produce,leafy,lettuce,spinach,greens],
  scope.suppliers=[DOLE FRESH VEGETABLES INC, FRESH EXPRESS INCORPORATED,
  TAYLOR FARMS, INC.], channel=telegram. `parse_profile(text)` parses plain
  English into a profile dict.
- **build_portfolio()** is idempotent (drops + reloads operator_sites).
  Call it before verify_m1.py or any M2 code that depends on operator_sites.
  If `load_mongo.py` is re-run, it clears operator_sites back to empty —
  must re-run `build_portfolio()` after.
