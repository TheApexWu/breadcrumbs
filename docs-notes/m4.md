## M4 — done (2026-08-22)

- **bridge/server.py** — the ONLY interface loop->frontend. Stdlib
  `http.server.ThreadingHTTPServer` on 127.0.0.1:8899 (no extra deps). Endpoints:
  `/operator_sites` (GeoJSON), `/response?recall=<id>` (live M2 Response),
  `/transcript?recall=<id>` (runs swarm, returns tool-call log),
  `/telemetry` (stub off-box; M6 wires NVML), `/healthz`. CORS `*` so the
  local-file console can fetch.
- **No drift by construction**: `/response` calls `sim/respond.respond()`
  directly — the bridge never recomputes numbers. Static `bridge/out/*.json`
  is generated by the same `respond()` so it matches byte-for-byte.
- **bridge/server.py --write-out** regenerates `bridge/out/*.json` AND
  `bridge/samples/*.json` (committed; console renders offline). Uses
  `force_alert=True` so the sample transcript is a real first-alert, not a
  deduped re-run. Brief + SMS also dumped to `out/` for the M5 Comms UI.
- **bridge/CONTRACT.md** — every endpoint + field with type + provenance class
  (real/modeled). Frontend wires `globe/food3d.html` from this doc alone.
- **Telemetry stub**: `{model, tokens_per_sec:null, unified_gb:null,
  unified_gb_total:128, watts:null, agents_concurrent:0, source:'stub'}`.
  M6 fills the nulls from NVML/tegrastats.
