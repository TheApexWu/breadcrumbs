## M2 — done (2026-08-22)

- **respond(recall)** in `sim/respond.py` computes the full Response:
  exposure (M1 `sim.operator.exposure`) x risk (distributor class1 +
  compounding via `db.queries.compounding`) x action (hold + swap to
  lowest-class1 hub). Deterministic (sorted fields, sorted camis).
- **distributor_risk**: matched by SHORT name (distributors collection stores
  "DOLE", recalls use "DOLE FRESH VEGETABLES INC"). Match rule: the
  distributor whose `firm` is a prefix of the recall's `recalling_firm`
  (uppercased). DOLE -> class1=205 (the real openFDA scorecard count).
  Fallback: `db.queries.scorecard()` by full firm name if no prefix matches.
- **compounding_count**: exposed sites with crit_violations>0 via
  `db.queries.compounding([camis...])`. For the Dole hero recall: 5/5 exposed
  sites have crit_violations>0 (values [11,10,8,8,10]).
- **swap_to**: lowest-class1 `is_hub:true` distributor, alphabetical tiebreak.
  BALDOR (class1=0) wins deterministically. Other 0-class1 hubs: US FOODS,
  RESTAURANT DEPOT, JETRO.
- **allergen_match**: only for `hazard_class=='allergen'` recalls. Maps each
  allergen -> food categories via MODELED `ALLERGEN_CATEGORIES` dict
  (category-level, NOT per-menu-item — label roadmap). Returns None for
  pathogen/foreign-material/other. Control asserted.
- **origin beat**: firm_state (REAL, from recall.state) + Comtrade commodity
  origin (REAL food-sources.json). Product->category inferred via keyword
  match (CATEGORY_KEYWORDS). Only Dairy&cheese, Nuts&spices, Fruit have
  Comtrade top_sources; Leafy greens/Seafood/etc. return empty (honest).
- **provenance**: Response.provenance = {real: [recall, compounding_count,
  distributor_risk, origin], modeled: [exposed_sites, allergen_match,
  recommendation]}. Each sub-object also carries its own `class` field.
