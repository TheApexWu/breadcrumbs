## M3 — done (2026-08-22)

- **agent/swarm.py** — five tool-calling roles over M0 aggregations + M2
  `respond()`. Run = `swarm.run(recall_number, db, adapter)`.
  - Watcher: `watch_feed` (the always-on Mongo CHANGE STREAM on recalls;
    `watch_change_stream(on_recall)` opens it. In the sync run() path the
    tool records the fired recall) -> `ingest_recall` (loads the doc).
  - Tracer: `trace_forward` -> the M0 `exposure` $lookup aggregation.
  - Risk: `score_risk.distributor` (real openFDA class1 via M2
    `_distributor_risk`) runs CONCURRENTLY with Tracer (ThreadPoolExecutor,
    max_workers=2 — they are independent aggregations). Then `score_risk`
    (compounding via `db.queries.compounding`) runs after (depends on
    exposed camis list).
  - Briefer: `brief` -> plain-language brief GROUNDED in the M2 Response.
    Every number traced to a Response field; labeled `instrument-not-oracle`.
  - Comms: `draft_sms` -> SMS + supplier hold notice (M5 wires the send).
- **ModelAdapter** — the SINGLE swap point. `backend="openrouter"` (off-box,
  OpenClaw runtime, calls OpenRouter z-ai/glm-5.2) <-> `backend="nemotron"`
  (on-box, NemoClaw, M6 wires the real endpoint). Same `complete(prompt,
  system)` interface; one dispatch branch. GLM-5.x sometimes returns
  `content:null` (answer in `reasoning`) — adapter falls back to
  `reasoning` so it always returns a string. `RUNTIME="OpenClaw"` tag.
  - The brief's narrative uses the LLM ONLY for a clean short sentence;
    reasoning dumps or long output fall back to the deterministic template.
    The numbers are ALWAYS from the Response (never the model).
- **agent_memory** (Mongo) — durable state + dedup. `record_run()` inserts
  {run_id, recall_id, decision, alert_sent, ts, response_summary}.
  `recall_state()` reads prior state; on re-run of the SAME recall the swarm
  RECALLS prior state, sets `deduped=True`, records a new memory doc with
  `alert_sent=0`, and does NOT re-alert. `alert_count()` = count of
  `alert_sent:1` docs for that recall — stays 1 across re-runs.
- **Transcript** — `Transcript.log(agent, tool, args, result, concurrent)`.
  Canonical subsequence (filtering concurrent extras): watch_feed ->
  ingest_recall -> trace_forward -> score_risk -> brief -> draft_sms.

## Gotchas for next iteration (M4 / M5 / M6)

- **M4 bridge**: serve `swarm.run()` output. The transcript is
  `out["transcript"]` (list of dicts, JSON-serializable via
  `json.dumps(..., default=str)`). The Response is `out["response"]` (the
  M2 Response). Brief = `out["brief"]`, SMS = `out["sms"]`. Sample payload
  for bridge/samples/: dump `swarm.run("F-0757-2022")` (drop _id from
  memory doc). Contract shapes already updated in bridge/CONTRACT.md.
- **M5 Comms**: `out["sms"]` = {sms, hold_notice, exposed_count,
  compounding_count, swap_to, class:'grounded'}. Wire the Telegram send
  here (token from env, never committed). The alert text already names the
  real product, exposed count, compounding count, swap target.
- **M6 on-box**: swap `ModelAdapter(backend="nemotron", base_url=<gb10
  NemoClaw endpoint>, model=<nemotron>)`. Set NEMOCLAW_URL env or pass
  base_url. The interface is identical — one line swap. Verify NemoClaw's
  exact API on the box (day-of, per PRD).
- **OpenRouter model id**: the OpenRouter HTTP id is `z-ai/glm-5.2`
  (NOT `openrouter/z-ai/glm-5.2` — that's the opencode model id format).
  OPENROUTER_MODEL env overrides.
- **verify_m3.py pops OPENROUTER_API_KEY** for determinism (grounded fields
  are deterministic; the LLM narrative is non-deterministic). The adapter
  is still exercised via the V3 interface checks. For a live-model demo
  run, leave the key set — grounding holds either way (asserted).
- **agent_memory is per-recall**: dedup is by recall_id (recall_number).
  Clear with `db.agent_memory.drop()` for a clean demo. The collection is
  NOT created by load_mongo.py — it's created on first insert by the swarm.
- **build_portfolio() must run before swarm.run()** if operator_sites is
  empty (e.g. after load_mongo.py re-runs). verify_m3.py calls it.
- The `watch_change_stream()` needs a Mongo replica set; in dev (standalone
  mongod) it falls back to a message + returns. The sync `run()` path is
  the demo entry point; the change stream is the always-on production watch.
